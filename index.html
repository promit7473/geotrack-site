The problem

A drone can take off with working GPS and lose it later. With a downward camera, an IMU, a height source and a map, it can keep estimating where it is by matching each frame to the map. Matching can fail in two ways. It can find nothing, which is easy to notice. It can also find many consistent matches at the wrong place, which looks like a good fix.

Current trackers judge a fix mostly from that fix alone, using fixed rules. This project asks whether they can do better.

Does a tracker's recent history reveal whether the current map fix is correct, beyond what the fix itself shows? If so, can a learned model use that to reject false fixes without discarding good ones?

Method

Known start

GPS works until a cutoff, which gives the start state. After that, only a local map crop around the prediction is searched.

Same matcher for every method

The matcher is frozen and fixes are logged, so any gain comes from trust and not from better matching.

Memory of previous frames

A GRU or LSTM carries a hidden state from frame to frame, so one convincing but wrong match can be judged against recent history.

Test the idea offline first

History must predict fix correctness on unseen routes before any learned tracker is built. If it doesn't, the plan changes.

How it will be evaluated

Results are reported against RTK-corrected ground truth with no trajectory alignment. The primary measures are false-fix rate and P95 horizontal error at equal availability. Flights are split by route, and comparisons are paired over flight segments. Attitude or height that depends on GPS is labelled as an oracle and reported separately.

These checks do not measure GPS-denied performance. Attitude comes from a GPS-aided INS, the maps are sharp aerial orthophotos, the filter starts at the true position, and everything comes from one 9 km stretch at about 650 m above ground. On this stretch a simple 20-inlier rule rejected every fix that was more than 20 m wrong, so it shows no problem for a learned trust model to solve yet. Harder terrain, lower altitude, satellite maps and independent attitude come next.

Data: Leaving the City, MARS-LVIG, NRW orthophotos, Copernicus DEM.
